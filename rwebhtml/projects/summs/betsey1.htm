ALFALFA Graduate Student Project

Proposal Title: Modeling the Leo Triplet and Leo Ring
Student Name: Betsey Adams
Adviser: Martha Haynes and Dave Kornreich
Context: Summer project
Institution: Cornell
Time frame: summer 2008
Other collaborators: Brian Kent, Riccardo Giovanelli, Sabrina Stierwalt
Publication expected? yes, 2008+

Description:

The Leo Triplet and Leo Ring are two structures in the Leo cluster with extended HI structure. ALFALFA provides a larger field of view for examining these structures than available in previous data sets. The goal is to combine the ALFALFA data with new simulations using the GADGET-2 code to understand the formation of these structures.



ALFALFA region:Leo region
ALFALFA data to be used: catalogs and data cubes
Other data sets to be used: GADGET-2 code
