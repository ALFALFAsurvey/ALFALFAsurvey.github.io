The Undergraduate Team Groups Project

Let's keep track of files for the groups which are currently being analyzed by members of the UAT.

  • UAT groups project
  • Working files for Zw1400 (more coming)
  • Link to the group sample, as it is.

Get the July 12th version of LOVEDATA (and, don't forget to love your data!). If you already updated to the July 5th version, just reinstall the AGC files (copy to IDL_ALFA, gunzip and un-tar). We strongly suggest that you make a backup of your old version (just in case...) before you install the new one.

** Brief description of what's here:
  • AGC records:   all AGC entries as of 07 July 2010 at all cz and including ones with no cz. If you would like to contribute to updating the AGC, you need to discuss with Martha; she'd be happy to have your help, but as we learned long ago, there is only one official AGC and so you need to work with her on how to accomplish this task.
  • A40 catalog:   all Code 1,2,9 in ALFALFA40 catalog as of 05 July 2010
  • AGC-SDSS cross list:   contains first-run identification of SDSS counterpart for objects in the AGC in specified region. Read the documentation.
