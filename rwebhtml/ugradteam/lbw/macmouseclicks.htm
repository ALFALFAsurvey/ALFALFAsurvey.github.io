A solution to MacOS mouse click issues

In September 2015, David Craig writes The X11 problem with mouse clicks is that "click through" is not enabled by default in newer versions of Xquartz on Macs. On mine in stye X11:Preferences:Windows I checked
  • Click-through Inactive Windows, and
  • Focus Follows Mouse (not sure this was necessary, but why not?)

    Also this website was helpful for the hint:
    http://exoplanets.astro.yale.edu/tutorials/macos/mouse_clicks.php
    But doing it from the shell prompt as the above site suggests did not s eem to work, or the GUI windows for Xquartz kept overriding it until I selected the check buttons in the Preferences panel.

    Also following the advice of some website I am using the Xquartz xterm instead of the OS X terminal app.
