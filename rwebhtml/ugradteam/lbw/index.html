The first step is to identify which sources are detected and which ones are not; the two classes will be treated differently.
Non-detections:We want to measure the rms noise in the baseline-subtracted, smoothed spectrum.
Detections: We want to measure the HI line flux, systemic velocity and velocity width and their errors, as well as the rms noise.

In both cases, we want to store the output in an IDL-readable file (akin to a "src" file in IDL_ALFA) and also to an ASCII version so that we can archive the output once and for all time. Once we get everything in place, reduction should go quickly.


More to come here as time permits and we think through the process.
