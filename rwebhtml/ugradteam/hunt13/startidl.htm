These instructions only apply to the 2013 workshop



  • In 2013, we are using a machine called "fusion00".

  • Login to that machine (using ssh) as "alfalfa" by typing
              ssh -X alfalfa@fusion00
    The password is written on the whiteboard.

  • Change to the directory of your team. For example
              cd /share/alfalfa/teama

  • Startup IDL for ALFALFA
    >   idl

  • As part of Hunt #1, we will have you try out the skyd procedure. First, you have to compile it
    >   .comp skyd
    and then you run it by typing
    >   skyd
    You input the coordinates of a position (or more than one, even a list in a file) on the sky you wish to examine, and the routine creates a file called skylinks.html in your team's directory which contains links to SDSS, SkyView, DSS2 blue and red and NED. You can then copy that file back to your laptop, load it into your browswer.... and follow the links!

If you run into any problems, ask any one of the experts!.
