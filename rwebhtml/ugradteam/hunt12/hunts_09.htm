The UAT09 Scavenger Hunts:

  • Hunt #0
    This exercise is designed to introduce the layout of the Arecibo dish, platform, the different feeds, Carriage House #1, the azimuth-zenith angle system and the sky as viewed from Arecibo. It requires no software or datasets, but an internet connection will help with the answer to the movie questions.....

    • Contact answer

    This hunt should be printed and included with welcome packet

  • Hunt #1
    This exercise is designed to introduce the strategies used by ALFALFA, the beam layout, spectrometer setup, sidereal time, precession, etc. It requires only basic calculations which can be done using a calculator, IDL or even a pencil and brain.

    Laptop/internet connection is required so that the galaxy can be investigated. BTW, there is nothing special about these galaxies other than that they have spectra both in the ALFALFA dataset and in the Cornell Digital HI Archive. Be sure to check out both!

  • Hunt #2
    This exercise will be designed to introduce the concepts associated with Level I processing, system temperature, calibration, drift scanning, RFI, lots of jargon etc. It requires examination of BPD and FLAGBB screenshots.

    • NUDET-GPS
    • For the question about finding out how many GPS satellites there are, see the link on the A2010 observers' page to Phil's IDL routines.

  • Hunt #3
    This exercise will focus on ALFALFA grids, source extraction, use of the ALFALFA catalog, the AGC, ALFALFA_IDL, SDSS, etc. TBD.
