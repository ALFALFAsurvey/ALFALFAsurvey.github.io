These instructions only apply to the 2010 workshop



  • In 2010, we are using the local machine called "maricao".

  • Login to that machine (using ssh) as "alfalfa". The password is written on the whiteboard.

  • Change to the directory of your team. For example, cd /share/alfalfa/teama

  • Startup IDL for ALFALFA
    >   idl
    >   @wasinit2
    >   @alfinit

    The above are the basic instructions. Below here, we suggest some interesting things to try if you have not already.

  • Try out the plotalfa procedure. A window pops up. Enter the coordinates of some interesting object (e.g., an object from UAT10/SH#1.14) in HHMMSSS+DDMMSS (note the decimal point in secs of RA is missing). You can adjust the size of the box. Figure out with your team (and by consulting an expert) what the symbols mean. plotalfa creates a couple of useful files in the directory where you run it. Try to figure out what they contain.

  • Try out the skyd procedure (and thank Schuyler for it!). It creates a file called skylinks.html in your team's directory which contains links to SDSS, SkyView, DSS2 blue and red and NED. You can then copy that file back to your laptop, load it into your browswer.... and follow the links!

If you run into any problems, ask Martha, Ann, Betsey, Becky or Riccardo.
