  • Ron and the St. Mary's team are going to check some positions for us. The problem here is that not all of the SDSS photometric survey was completed when we did SDSS matching for the data taken early on. We need to recheck whether or not there is SDSS photometry and whether the positions are good. This is not a particularly fun job, but it is an important one! Here are two files: positioncheck.150629.agclist.txt and positioncheck.150629.sdss.txt. Use the first file to record the outcomes; the second one just contains the list of galaxies for use with the SDSS image list server. See the top of the first file for instructions on what to do.

  • Here is a file which contains the SDSS and ALFALFA parameters for galaxies in α.70 with log MHI:[8.0,8.8]. It would useful is someone explored the parameter space in various bands including colors in SDSS only and incorporating GALEX-NUV, notably the (NUV-r) vs r-band color-magnitude diagram. Corrections need to be made for galactic and internal extinction before making the CMDs. Anyone game?   Keep in mind that real data are likely to contain bogus numbers; I'm sure there are some herein.

  • Team SMCC:   Here are two related files: a csv file and simple list for you to work with. This sample contains all current (as of 8Jul2015) entries in the AGC which (1) lie in the proposed Arecibo APPSS region, (2) have no measured redshift; (3) are either unclassified or classified as spiral (BSTEINTYPE:[120-420]) and (4) have not been flagged (manually, in the AGC) as being too close to a bright star (IBANDQUAL=7). Note that the classifications are pretty crude, so don't take them too literally. However, this provides a starting point; there are almost 2400 objects. Things to do include:
    • Use the list file and the SDSS image list tool to identify any galaxies that look "funny" or "bad" e.g., ones that are multiple with several galaxies within 3 armins, very peculiar morphologies, uncertain identifications, etc. Separate the original list into "good" and "bad" galaxies. Be sure to make new files giving them names that are easy to identify ("good", "bad" and include the date).
    • Once you have a "good" file, use TOPCAT to match it with the csv file, and generate a new csv file with only the "good" galaxies.
    • Try to match this list with both the SDSS and GALEX. I, David and others can help you figure out how to do this. (I'll try to suggest instructions for SDSS soon but maybe someone else can help.)
