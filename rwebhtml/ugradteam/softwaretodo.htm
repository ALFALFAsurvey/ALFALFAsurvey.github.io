Useful things someone might do for ALFALFA

  • Write up a web page of "undocumented" ALFALFA utilities available in FORTRAN and/or IDL. Make sure they are generally available.
  • Write an IDL version of "plotall" (FORTRAN) which is based on "plotanlfa.pro" to plot a series of drifts at some declination. frequency and velocity
  • Write a widget which converts RA,DEC hhmmss.s+ddmmss to hh.h,dd.d and ddd.d,dd.d
  • Write a version of "agcbrowse.pro" which works on a user specified (rectangular) box.
  • There are several versions of AGC readers; let's make one available to everyone which relies on the IDL structured version of the catalog.
