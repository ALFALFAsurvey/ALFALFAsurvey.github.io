IDL Codes to read in catalogs

  • ALFALFA catalogs: Code
    This code can be inserted in your program to read either non-public or web-archive ALFALFA catalogs (selected through use of a keyword: /webarch). Alternatively extract the code suitable for the catalog you are using. You need to set a number greater than the number of galaxies in the file and check the number of header lines.

  • gals.txt from plotalfa : Code
    This code can be inserted in your program to read files output by plotalfa (AGC information for galaxies within a box on the sky).
    Note that a feature in plotalfa output sometimes shifts the coordinate columns. If this happens, reading will crash. Workaround: manually fix coordinate columns to expected format.

Please let Becky know if you find errors. If you have a better code to read in catalogs or a code that allows other options, please send to Becky for posting.
