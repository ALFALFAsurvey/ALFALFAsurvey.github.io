  • Let's learn to query the SDSS database using the Structured Query Language (SQL)
    • Review the SDSS SQL help page.

    • Here is the query we are going to use to extract information about galaxies in the Zw1400+0949 region that have spectra in the SDSS database. 
      SELECT
 p.ra, p.dec,s.z,s.zerr,p.petroR90_r,p.petroR50_r,p.expAB_r,
 p.petroMag_u,p.petroMag_g,p.petroMag_r,p.petroMag_i,p.petroMag_z,
 p.fiberMag_r,
 p.lnLExp_r, p.lnLDeV_r, p.isoA_r, p.isoPhi_r, l.sigma, l.sigmaErr,
  l.ew, l.ewErr, l.continuum, l.chisq, l.nu, s.zWarning,p.objID
FROM PhotoObj p, SpecObj s, SpecLine l
WHERE
 p.SpecObjID = s.SpecObjID AND
 p.SpecObjID = l.specobjID AND
 s.specClass=2 AND
 l.lineID = dbo.fSpecLineNames('Ha_6565') AND
 p.ra >=207.95 AND p.ra <= 214.15 AND
 p.dec >= 5.86 AND p.dec <=12.15 AND
 s.z <= 0.061
order by p.ra
