An Introduction to using IDL for ALFALFA

The best way to learn IDL is to get hold of the book "Practical IDL Programming" by Liam E. Gumley (Morgan Kauffman Publishers) and devour it! That's how most of us learned.

Use the IDL Development Environment (IDLDE) for writing programs. In a terminal where you are positioned in the directory where you will also run IDL, type
                > idlde &
and the environment window will pop up. You can then start IDL as usual.
