    Things to do (more or less) daily
    1. Check the observing log.
      -- Read the observer comments and make a note of any weird occurrences. If there were hardware issues, send an email to Dana Whitlow and Phil Perillat asking for updates. (Note: I may do this also, in which case I will cc you on the email. Please cc me if you write.)
      -- Check that the observing log is correct in its basics, e.g., that the coordinates are correct, etc. If you don't understand what the observer has written, send him/her/them a message asking them to clarify (and correct the files!). Better to catch oversights/typos/errors now than to be confused later.

    2. Transfer the raw IDL files from AO to CU:
      The observer runs filecreator in the directory: /share/a2010-2/data/YY.MM.DD. You need to copy them to /home/dorado3/dorado13/galaxy/idlraw. There is a script there that will copy the files for you:
      cd /home/dorado3/dorado13/galaxy/idlraw
      Edit the rsync.csh file to update the block designation.
      Type:     source rsync.csh

    3. Run the calibration and BPD processes:
      Work in /home/palfa/galaxy/fall12/, creating a directory for each observing block and following the Instructions for Level I processing as abbreviated in the log_processing file we create the first night.



    Check for abandoned VNC sessions (occasionally)

    If the observer, or others practicing CIMA, do not exit their VNC sessions cleanly, then the sessions get abandoned. This happens fairly often (despite all the instructions...). So, every few days, we need to clean things up. Do this when no one should be running a VNC session.
    1. Check for abandoned sessions and clean up the ~a2010/.vnc area.
      cd ~a2010/.vnc
      ls
      If there are files there, e.g. dataview.naic.edu:13.pid, then there may be an abandoned VNC session e.g. on dataview.
      Remove the files here
      rm *log *pid

    2. Kill the abandoned sessions on the machine where they are running.
      ssh -X a2010@dataview
      ps -ecf | grep a2010
      Check to see if the output list contains any reference to Xvnc :NN
      a2010 10261 1 TS 24 Sep10 ? 00:01:22 Xvnc :13 -desktop dataview.naic.edu:13 (a2010) -httpd /usr/share/vnc/classes -auth /home/a2010/.Xauthority -geometry 1200x900 -depth 16 -rfbwait 30000 -rfbauth /home/a2010/.vnc/passwd -rfbport 5913 -pn
      If so, then kill the job by its PID
      kill -9 10261
      Make sure there is nothing left running that shouldn't be there.
